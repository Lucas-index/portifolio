Sobre Mim

Sou um jovem desenvolvedor apaixonado por tecnologia, atualmente cursando o 2º ano do Ensino Médio no SESI-SP. Busco minha primeira oportunidade na área de Tecnologia e Desenvolvimento Web, onde posso aplicar meus conhecimentos em programação, arquitetura de sistemas e design de interfaces.

Tenho experiência prática no desenvolvimento de um Sistema de Solicitações Internas completo, construído do zero com Laravel (PHP), FastAPI (Python) e React — três camadas independentes se comunicando via API REST, com banco de dados MySQL e containerização via Docker Compose. O sistema inclui autenticação com Sanctum, controle de acesso por papéis, histórico de auditoria, SLA automatizado, relatórios em Excel e integração com Machine Learning para classificação automática de chamados usando TF-IDF e Regressão Logística, com threshold calibrado e fallback para triagem humana. Também implementei notificações por e-mail com fila assíncrona, busca e filtro em tempo real, matriz de confusão no painel administrativo e um loop de retreinamento que incorpora correções humanas para melhorar o modelo continuamente.

Busco sempre acompanhar as tendências da área e participei da FIRST LEGO League (FLL) com projetos inovadores em engenharia e robótica.
